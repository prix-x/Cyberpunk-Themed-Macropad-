# Cyberpunk-Themed-Macropad-
This project is a cyberpunk themed 4-key macropad with and RGB led and an OLED screen. Key 1 opens my custom AI, Key 2 instantly types my Gmail for fast login/signup, and Key 3 boots my Spotify playlist. Key 4 locks you into focus mode, where you set timer; if you try to escape early, you must solve a tough math problem to unlock your laptop.
